About EduPulse AI

Addressing student dropouts through proactive, data-informed intervention strategies.

🎯

The Academic Risk Challenge

Higher education institutions often identify struggling students too late—after midterms or final grading. EduPulse AI continuously analyzes behavioral signals like attendance trends, study hours, LMS logins, and assignment completion rates to catch disengagement before failure occurs.

💡

Intelligent Intervention Engine

Instead of relying solely on GPA, EduPulse AI uses a trained Random Forest model (90% evaluation accuracy) to classify students into High, Medium, and Low risk tiers, generating prioritized support roadmaps mapped directly to peer tutoring, counseling, and advisor check-ins.

Core Platform Capabilities

Comprehensive tools designed for academic advisors, educators, and institutional leadership.

📊

Cohort Analytics Overview

Real-time summary KPIs (Total Cohort, High Risk %, Avg GPA, Attendance, Assignment Rate) accompanied by Plotly donut charts, scatter plots, and department risk breakdowns.

🎓

Student Risk Predictor

Select individual student profiles to view Machine Learning predictions across 3 risk tiers (`High`, `Medium`, `Low`) with exact class probability distributions and placement readiness scores.

👤

Explainable Indicators

Transparent indicator model explanations comparing student metrics against cohort averages, weighted by Random Forest feature importances with status badges.

🛠️

Actionable Interventions

Context-aware recommendation engine mapping low scores to specific recovery actions—mandatory advisor intake, peer tutoring pods, LMS workshops, and counseling referrals.

🔮

What-If Scenario Simulator

Interactive simulation sandbox allowing academic coaches to adjust attendance, study hours, and stress levels to observe simulated risk score shifts in real-time.

📁

Filtered Student Explorer

Interactive student directory with multi-attribute filtering by Major, Grade Level, and Risk Level, featuring sanitized CSV dataset export.

System Architecture & Workflow

From synthetic student metrics to automated academic intervention planning.

1

Student Dataset

1,200 student records generated via realistic multivariate distributions (`students_1200.csv`).

2

Data Loader

Cleansing, missing value validation, and cohort average statistical indexing (`data_loader.py`).

3

Random Forest Classifier

120 decision trees trained with class balancing & 80/20 stratified split (`train_model.py`).

4

Risk Inference

Computes class probabilities, success scores (0-100), and placement readiness (`model_utils.py`).

5

Support Interventions

Maps risk drivers to prioritized academic check-ins and tutoring enrollment (`recommendations.py`).

Technology Stack

Built with reliable Python open-source data science & machine learning libraries.

🐍 Python 3.14

Core programming language powering data generation, model inference, and Streamlit dashboard orchestration.

⚡ Streamlit

Interactive web application framework providing cached data loading (`@st.cache_data`) and model deserialization (`@st.cache_resource`).

🤖 Scikit-Learn

Machine learning library providing `RandomForestClassifier` with balanced class weights and feature importance extraction.

🐼 Pandas & NumPy

High-performance data manipulation, filtering, Z-score computation, and dataset CSV sanitization.

📊 Plotly

Interactive chart rendering engine producing custom dark-themed donut charts, scatter plots, and horizontal bar charts.

🔐 SHA-256 Integrity

Checksum verification enforcing model artifact integrity validation prior to `joblib.load()` deserialization.

⚠️

Hackathon & Prototype Disclaimer

EduPulse AI uses a synthetically generated student dataset (`data/students_1200.csv`) and a proof-of-concept Random Forest classifier for hackathon demonstration. It is not validated for real-world institutional deployment, FERPA compliance, or high-stakes academic decision-making. Prior to live deployment, integration with university Canvas/Blackboard LMS APIs and SAML/OAuth single sign-on is required.
